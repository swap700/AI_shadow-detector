# ShadowScan — AI Shadow Analytics Detector

> **Enterprise AI governance platform that detects shadow AI usage, sensitive data uploads, and prompt leakage across your organization.**

## The Problem

Organizations today face a silent data governance crisis — **Shadow AI**.

Employees are uploading sensitive Excel files, customer databases, and confidential documents into ChatGPT, Gemini, Grok, and other unapproved AI tools — without IT or Security knowing. Companies have no visibility into:

- Which datasets are leaking to external AI tools
- Who is using unauthorized AI in their workflows
- Which prompts are exposing sensitive or confidential information

---

## What ShadowScan Does

ShadowScan is a monitoring platform that gives security and IT teams full visibility into AI usage across the organization.

| Feature | Description |
|---|---|
| **AI Usage Monitor** | Tracks every employee using unauthorized AI tools, with risk classification |
| **Sensitive Upload Detector** | Flags files uploaded to AI tools — PII, revenue data, contracts, health records |
| **Prompt Leakage Scanner** | Detects sensitive data patterns inside prompts sent to AI tools |
| **Data Exposure Heatmap** | Visual risk matrix showing which departments are leaking data to which AI tools |
| **AI Report Detector** | Identifies internally circulated reports that were generated by unauthorized AI |
| **Prompt Risk Analyzer** | Paste any prompt and get an instant risk score with highlighted sensitive patterns |
| **Policy Settings** | Configure blocked tools, classification rules, and alert thresholds |

---

## Killer Feature: Data Exposure Heatmap

The heatmap provides an at-a-glance view of your organization's AI exposure risk — a matrix of **Departments × AI Tools**, colored by cumulative risk score. Click any cell to drill down into the exact files and users behind the exposure.

This is the kind of visual that makes the problem immediately obvious to a CISO or board.

## How It Works (Architecture)

```
[Employee Machine]
      │
      ▼
[Browser Extension / Network Proxy]
      │  Intercepts uploads & prompts to AI tool domains
      ▼
[Classification Engine]
      │  Pattern matching: PII, revenue, M&A, health data, etc.
      │  Risk scoring per event
      ▼
[Backend API + Database]
      │  Stores flagged events, user sessions, file metadata
      ▼
[ShadowScan Dashboard]
      │  Real-time monitoring, heatmap, alerts, exports
      ▼
[Security / IT Team]
```

**Current status:** This repository contains a fully functional frontend prototype with simulated data. The Prompt Risk Analyzer runs real pattern-matching logic on any text you provide.
